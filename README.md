# Pipeline Scoring-а вертикальных видео для Trendsee

## 1. Общая концепция
Цель алгоритма — отобрать **Top-30 лучших референсов** из массива в 500-1000 видео, основываясь на нише пользователя, его целях и желаемом формате контента.

Для оптимизации стоимости и скорости обработки предлагается архитектура **«Воронки фильтрации» (Filtering Funnel)**. Вместо того чтобы прогонять все видео через дорогой анализ (Vision/LLM), мы последовательно сужаем выборку, переходя от самых дешевых методов к самым точным.

### Схема Pipeline:
`1000 видео` $\rightarrow$ **[Stage 1: Hard Filter]** $\rightarrow$ `~300 видео` $\rightarrow$ **[Stage 2: Soft Scoring]** $\rightarrow$ `~100 видео` $\rightarrow$ **[Stage 3: Deep Analysis]** $\rightarrow$ `Top-30`

---

## 2. Детальное описание этапов

### Этап 1: Hard Filter (Дешёвый / Мгновенный)
**Цель:** Отсечь «информационный шум» и контент, который физически не может быть качественным экспертным референсом, используя логистические методы `if-else` и библиотеку **RegEx**. На этом этапе используется **отрицательная логика**: мы не ищем соответствие формату, а удаляем то, что точно не подходит.

**Критерии отсева (Hard Reject):**
1. **Технический фильтр (Duration):**  $\text{Duration} < 3\text{s}$ (ошибки/глитчи). $\text{Duration} > 180\text{s}$ (полноценные влоги/подкасты, не являющиеся Reels-референсами).
2. **Семантический шум:** Удаление видео со стоп-словами из нерелевантных ниш (например: *«казино», «ставки», «gameplay», «asmr», «full movie»*).
3. **Детекция ботов/накруток:** `if (views > 10000 && (likes + saves + comments) < 10) return REJECT` Удаление видео с аномальными метриками (например, $\text{views} > 10\,000$, но сумма лайков, сохранений и комментариев $\approx 10$).
4. **Срез актуальности (Recency Cut):** `if (video.date < '2022-01-01') return REJECT` Жесткое удаление контента старше определенного срока (например, $> 3$ года), так как тренды вертикальных видео устаревают быстро.
5. **Валидация автора:** `if (is_empty(caption) && is_empty(bio) && duration < 10) return REJECT` Удаление видео от «пустых» аккаунтов (отсутствие Bio, фото профиля, а длительность видео всего 5-7 секунд), что минимизирует попадание низкокачественного спам-контента.
6. **Лингвистический фильтр:** Отсев видео на языках, которые не указаны в предпочтениях пользователя.

**Данные:** `duration`, `caption`, `bio`, `views`, `likes`, `saves`, `comments`, `date`, `language`.

---

### Этап 2: Soft Scoring (Дешёвый / Средний)
**Цель:** Ранжирование оставшихся видео по смысловой близости к нише и статистической виральности.

**Признаки для скоринга:**
1. **Semantic Score ($S_{sem}$):** Косинусное сходство между вектором расширенного запроса пользователя (Ниша + синонимы) и вектором строки `(Bio автора + Caption видео)`.
2. **Viral Score ($S_{viral}$):** Относительный показатель виральности:
 
$$
\text{RawViral} = \frac{\text{Views}_{current}}{\text{AvgViews}_{author}}
$$

Для нормализации используем функцию насыщения (чтобы видео с миллионами просмотров не «сломали» формулу):

$$
S_{viral} = \tanh(\text{RawViral} - 1)
$$  

- **$\text{RawViral} = 1\  \Rightarrow\  \tanh(1-1) = 0$** (Средний результат → нулевой балл)
- **$\text{RawViral} > 1\ \Rightarrow\ \tanh(\text{positive value}) > 0$** (Видео-хит → положительный балл).
- **$\text{RawViral} < 1\ \Rightarrow\ \tanh(\text{negative value}) < 0$** (Видео-провал → отрицательный балл)

Вычитаем единицу, чтобы считать виральность не как абсолютное значение, а как отклонение от среднего. Таким образом, балл выше нуля получают только те видео, которые объективно "залетели" лучше обычного для данного автора

3. **Коэффициент свежести (Rec)** Применяется экспоненциальное затухание, чтобы приоритезировать актуальные тренды:

$$
Rec = e^{-\lambda t}
$$

Где *t* — количество дней с даты публикации, *λ* — коэффициент затухания.

**Цель Охваты → Высокий `λ` (Быстрое затухание)**:
- Звук, который был популярен 2 месяца назад, сегодня может вызвать у зрителя чувство «устарелости». Здесь нам нужны максимально свежие видео. Если видео старое, его ценность как референса для охватов падает стремительно.

**Цель Лидогенерация → Низкий `λ` (Медленное затухание)**:
- Качественный разбор того, «Как составить ТЗ для дизайнера», будет актуален и сегодня, и через полгода, и через год. Принципы хорошего дизайна и продаж меняются медленно. Если видео было супер-полезным (высокий Utility Score), оно остается ценным референсом даже спустя время.

**Цель Идеи для контента `λ` Средний**:
- Здесь нужен баланс. Пользователю интересны и текущие тренды, и проверенные временем классические темы.

4. **Goal Score ($S_{goal}$):** Расчет метрики в зависимости от цели пользователя:
   - **Охваты $\rightarrow$** $\text{Engagement Rate} (\frac{\text{Likes} + \text{Comments} + \text{Shares}}{\text{Views}})$.
   - **Лидогенерация $\rightarrow$** $\text{Utility Rate } (\frac{\text{Saves + Shares}}{\text{Views}})$.
   - **Идеи для контента $\rightarrow$** $\text{Discussion Rate } (\frac{\text{Comments}}{\text{Views}})$.

Финальный балл видео вычисляется как взвешенная сумма всех показателей, умноженная на коэффициент свежести:

$$
\mathrm{TotalScore}=\left(S_{sem}W_{sem}+S_{viral}W_{viral}+S_{goal}W_{goal}\right)\cdot\mathrm{RecencyDecay}
$$

**Распределение весов ($W$) в зависимости от цели пользователя:**

| Цель пользователя | $W_{sem}$ | $W_{viral}$ | $W_{goal}$ | Decay ($\lambda$) | Обоснование |
|--------|--------:|--------:|--------:|--------|----------|
| **Охваты** | 0.3 | 0.5 | 0.2 | $\lambda_{high}$ | Максимальный приоритет на «взлом» алгоритмов (виральность) |
| **Лидогенерация** | 0.4 | 0.2 | 0.4 | $\lambda_{low}$ | Баланс между экспертностью ниши и полезностью (сохранения) |
| **Идеи для контента** | 0.5 | 0.1 | 0.4 | $\lambda_{mid}$ | Приоритет на точность темы и обсуждения в комментариях |

---

### Этап 3: Deep Analysis (Дорогой / Точный)
**Цель:** Точная верификация формата и финальный отбор Top-30.

**Методы анализа:**
1. **Транскрибация (Whisper STT):** Перевод аудио в текст для анализа структуры. Поиск паттерна: «Хук $\rightarrow$ Тело $\rightarrow$ Призыв (CTA)». Это позволяет отличить «Сценарии» и «Talking Head» от простого видеоряда.
2. **Vision-анализ (GPT-4o / Claude 3.5):** Анализ 3-5 ключевых кадров для подтверждения визуального формата:
   - **Talking Head:** Лицо человека занимает $\approx 50\%$ кадра.
   - **Lazy Reels:** Эстетичный фон + наложенный текст.
   - **Tutorial/Screencast:** Виден интерфейс софта (например, Figma).
   - **Threads:** Статичные скриншоты текстовых постов.
3. **LLM Reasoning:** Генерация финального объяснения, почему конкретное видео выбрано как лучший референс.

**Данные:** Видеофайл / Ссылка $\rightarrow$ Аудио $\rightarrow$ Кадры.

---

$$
\mathrm{TotalScore}=\left(S_{sem}W_{sem}+S_{viral}W_{viral}+S_{goal}W_{goal}\right)\cdot\mathrm{RecencyDecay}
$$

## 3. Scoring-формула

Финальный балл видео на втором этапе рассчитывается по формуле:

$$
\mathrm{TotalScore}
=
\left(
S_{sem} W_{sem}
+
S_{viral} W_{viral}
+
S_{goal} W_{goal}
\right)
\cdot
R
$$

**Распределение весов ($W$) в зависимости от цели пользователя:**

| Цель пользователя | $W_{sem}$ (Ниша) | $W_{viral}$ (Виральность) | $W_{goal}$ (Целевая метрика) |
| :--- | :---: | :---: | :---: |
| **Охваты** | 0.4 | 0.4 | 0.2 (ER) |
| **Лидогенерация** | 0.5 | 0.2 | 0.3 (Saves/Shares) |
| **Идеи для контента** | 0.6 | 0.1 | 0.3 (Comments) |

---
